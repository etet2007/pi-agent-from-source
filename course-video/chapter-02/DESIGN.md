## Style Prompt

Technical keynote: a restrained dark presentation for source-code education.
Architecture diagrams must be tied to visible source evidence: README lines,
package metadata, imports, or type definitions. Code is evidence, not wallpaper.

## Colors

- Canvas: `#0B0E14`
- Raised surface: `#141923`
- Primary text: `#F1F4F8`
- Secondary text: `#A9B2C3`
- Accent blue: `#4C8DFF`
- Runtime purple: `#9B7CFF`
- Tool green: `#58C792`
- Session amber: `#FFB85C`

## Typography

- Headline and Chinese body: `Arial, sans-serif`
- Code and technical labels: `"JetBrains Mono", monospace`

## What NOT to Do

- No unexplained architecture names.
- No tiny source-code screenshots.
- No package boxes without source evidence.
- No decorative motion that hides the dependency direction.
