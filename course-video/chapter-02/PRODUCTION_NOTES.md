# 第一章制作经验

1. 文稿要短句化。每句只讲一个动作或判断，后续字幕才容易逐句校准。
2. 画面要先展示真实证据，再抽象成模型。观众需要知道结论从哪里来。
3. 终端录屏不能只是滚动输出。必须同时说明当前目录、输入、关键输出和下一步为什么看这里。
4. 标题不能抛陌生词或奇怪数字。首次出现的术语要有上下文。
5. 字幕不能只按字数估算。第二章开始使用音频静音点辅助生成每句时间，再保留手工覆盖入口。
6. 文稿文件是主入口：先改 `narration.txt`，再重新生成音频、时间轴和视频。
7. 章节工程要独立。每章有自己的 `narration.txt`、`timing-data.js`、`index.html` 和渲染产物。

# 第二章制作目标

第二章先建立源码地图，不急着进入深层实现。

观众看完后应该知道：

- Pi 不是单个聊天界面，而是 Agent Harness。
- 四个核心 package 分别解决不同问题。
- `StreamFn` 和 `AgentTool` 是核心循环依赖的两个抽象。
- `Agent`、`AgentSession`、`SessionManager` 不是同一个东西。
- 后续源码精读应该沿调用链读，而不是按目录从上到下扫。
