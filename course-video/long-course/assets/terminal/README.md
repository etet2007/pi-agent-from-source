# 终端视频素材

所有 `*-vhs.mp4` 均由 `capture/*.tape` 生成，分辨率为 1440×900。

`07-live-run-replay-vhs.mp4` 是 2026 年 6 月 14 日真实在线 Session 的
确定性重放，不是重新模拟的工具顺序。其公开输入来自：

```text
evidence/live-run-2026-06-14/session.public.json
```

`08-session-chain-vhs.mp4` 使用同一真实 Session 的脱敏 `id/parentId`
投影，展示 JSONL 追加顺序如何组成一条可追溯分支。

旧的 `01-fixture-failure.mov` 是桌面采集方案的对照素材，正式剪辑使用
`01-fixture-failure-vhs.mp4`。
