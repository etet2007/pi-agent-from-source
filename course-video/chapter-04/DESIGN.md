## Style Prompt

Technical keynote: a restrained dark presentation for source-code education.
Source code is shown as evidence, never as wallpaper. Use the same restrained
dark keynote language as chapter 01: square panels, visible source symbols,
event names, function names, or concrete runtime states.

## Colors

- Canvas: `#0B0E14`
- Raised surface: `#141923`
- Primary text: `#F1F4F8`
- Secondary text: `#A9B2C3`
- Accent blue: `#4C8DFF`
- Success green: `#58C792`
- Failure red: `#FF6B74`

## Typography

- Headline and Chinese body: `Arial, sans-serif`
- Code and technical labels: `"JetBrains Mono", monospace`

## What NOT to Do

- No abstract AI magic language.
- No tiny source-code screenshots.
- No unexplained architecture names.
- No decorative gradients, glass cards, or playful bounce.
